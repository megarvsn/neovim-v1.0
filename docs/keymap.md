## 1. Навигация и правки (базовый Neovim motion)

| Клавиши | Действие |
|---|---|
| `h j k l` | перемещение по символам |
| `w` / `b` / `e` | слово вперёд / назад / конец слова |
| `W` / `B` / `E` | то же, но по «БОЛЬШИМ» словам (с пробелами) |
| `0` / `^` / `$` | начало строки / первый символ / конец строки |
| `gg` / `G` / `{n}G` | начало файла / конец файла / строка n |
| `{` / `}` | абзац вверх / вниз |
| `%` | к парной скобке/тегу (html: открывающий ↔ закрывающий, matchup) |
| `f{x}` / `t{x}` | до символа x / перед символом x (`;` повтор, `,` назад) |
| `.` | повтор последнего изменения |
| `dd` / `yy` | вырезать/копировать строку |
| `p` / `P` | вставить после/перед |
| `o` / `O` | новая строка после/перед |
| `u` / `Ctrl+r` | undo / redo |
| `<Esc>` | снять подсветку поиска |
| `zz` / `zt` / `zb` | центрировать/прижать вверх/вниз текущую строку |
| `m{a}` / `'a` | поставить метку a / перейти к метке a |
| `s` / `S` / `gs` | leap: прыжок к тексту на экране / в других окнах / «бумеранг»-правка в любом окне (`Esc` — возврат) |
| `*` / `#` | поиск слова под курсором вниз / вверх |
| `Ctrl+o` / `Ctrl+i` | назад / вперёд по списку прыжков (jumplist) |
| `''` | вернуться на прежнее место (после прыжка) |
| `gi` | вернуться в режим вставки (в буферах с LSP — к реализации символа) |
| `d{d}` / `c{c}` / `y{y}` | операторы: вырезать/заменить/скопировать + объект (см. таблицу 1.1) |
| `dt{c}` / `df{c}` | вырезать до символа c / вместе с ним |
| `D` / `C` / `Y` | вырезать/заменить/копировать до конца строки |
| `xp` | поменять местами соседние символы |
| `za` / `zR` / `zM` | свернуть/развернуть блок / всё развернуть / всё свернуть (по дереву Treesitter) |
| `Ctrl+a` / `Ctrl+x` | увеличить / уменьшить число под курсором |

### 1.1. Текстовые объекты (работают с `d`, `c`, `y`, `v`)

| Объект | Что выделяет (i — «внутри», a — «с границей») |
|---|---|
| `iw` / `aw` | слово / слово с пробелом |
| `i"` / `a"` | содержимое кавычек / с кавычками |
| `i(` / `a(` | внутри круглых скобок / с ними |
| `i{` / `a{` | внутри фигурных скобок / с ними |
| `i[` / `a[` | внутри квадратных скобок / с ними |
| `it` / `at` | содержимое HTML-тега / тег целиком (удобно для вёрстки) |
| `ip` / `ap` | абзац / абзац с пустой строкой |
| Пример | `ci"` — заменить строку в кавычках; `dit` — очистить содержимое тега; `ya(` — скопировать функцию |

## 2. Файлы, буферы, вкладки

| Клавиши | Действие |
|---|---|
| `<leader>ff` | найти файл по имени (Telescope) |
| `<leader>fr` | вернуть последний результат Telescope |
| `<leader>fb` | переключиться на буфер (Telescope) |
| `<leader>fo` | недавно открытые файлы (Telescope) |
| `<leader>e` | дерево файлов (neo-tree) |
| `<leader>o` | открыть текущий файл в браузере (вёрстка; php-окружение не грузится) |
| `<leader>w` | сохранить файл |
| `<leader>bd` | закрыть текущий буфер (вкладку) |
| `<Tab>` / `<S-Tab>` | следующая / предыдущая вкладка |
| `<Leader>x` | выбрать вкладку на закрытие (BufferLinePickClose) |
| `<C-x>` | закрыть все вкладки, кроме текущей |
| `<C-h/j/k/l>` | переключение окна: влево/вниз/вверх/вправо |
| `Alt+h/j/k/l` | размер окна: шире/ниже/выше/уже |
| `\|` / `\` | вертикальный / горизонтальный сплит |
| `:w` / `:q` / `:wq` / `:qa` | сохранить / закрыть / сохранить+закрыть / закрыть всё |
| `:bd` / `:b {имя}` | закрыть буфер / перейти к буферу по имени |

## 3. Поиск и замена

| Клавиши | Действие |
|---|---|
| `/текст` | поиск вперёд (`n` — следующий, `N` — предыдущий) |
| `?текст` | поиск назад |
| `:%s/old/new/g` | замена по всему файлу |
| `:%s/old/new/gc` | замена с подтверждением каждого вхождения |
| `:'<,'>s/old/new/g` | замена в выделении (визуальный режим) |
| `<leader>fw` | поиск текста по всем файлам проекта (Telescope live_grep) |
| `<leader>f/` | нечёткий поиск по текущему файлу |
| `<leader>fs` | замена по всем файлам проекта с превью (Spectre); в выделении — только выделенное |
| `<leader>fS` | то же, но только в текущем файле |
| `]q` / `[q` | следующий / предыдущий результат поиска (quickfix) |
| `gn` | выделить следующее совпадение поиска (работает с `d`/`c`/`y`) |
| `cgn` | заменить следующее совпадение и повторять через `.` |
| `:noh` | сбросить подсветку поиска |
| `:g/паттерн/d` | удалить все строки с паттерном |
| `:g/^$/d` | удалить пустые строки |
| `:sort` / `:sort i` | отсортировать выделенные строки (`i` — без учёта регистра) |

Синтаксис шаблонов vim-regex — `:h pattern` и подробный справочник с примерами:
[regex.md](regex.md). Практика замен «всё сразу / с подтверждением» — глава 4
туториала: [tutorial/04-search-replace.md](../tutorial/04-search-replace.md).

## 4. Визуальный режим

| Клавиши | Действие |
|---|---|
| `v` | посимвольное выделение |
| `V` | выделение строк |
| `Ctrl+v` | блочное (колоночное) выделение |
| `o` / `O` | перебросить курсор в другой конец выделения |
| `gv` | восстановить последнее выделение |
| `>` / `<` | сдвиг выделенного вправо/влево |
| `J` | склеить строки |
| `u` / `U` | в нижний/верхний регистр |
| `viw` / `vaw` | выделить слово / слово с пробелом |
| `vi"` / `vi(` / `vi{` | выделить в кавычках / скобках / фигурных скобках |
| `vat` / `vit` | выделить HTML-тег целиком / только его содержимое |
| `I` / `A` в `Ctrl+v` | вставить текст в начало/конец каждой строки блока |
| `~` | переключить регистр выделенного |
| `=` | выровнять/отформатировать выделенное отступом |
| `r` в блочном режиме | заменить выделенный блок символом |

## 5. LSP и код

| Клавиши | Действие |
|---|---|
| `gd` | перейти к определению (в html — выбор определений класса/ID в стилях) |
| `<leader>lC` | открыть список определений класса/ID под курсором в css/scss (из любого файла, в т.ч. php+html); выбор `Enter` — переход к строке |
| `gi` | перейти к реализации |
| `<Leader>D` | перейти к типу |
| `K` | документация (hover) |
| `<Leader>lr` | переименовать символ |
| `<Leader>la` | быстрые действия (code actions) |
| `<Leader>lf` | форматировать |
| `<Leader>ls` | подсказка по сигнатуре (signature help) |
| `]d` / `[d` | следующая / предыдущая ошибка (с всплывающим её текстом) |
| `<leader>qq` | все ошибки проекта (Trouble) |
| `<leader>qQ` | ошибки текущего файла (Trouble) |
| `<leader>cs` | символы файла (Trouble) |
| `<leader>cl` | определения/ссылки символа (Trouble) |
| `Ctrl+Space` | вызвать автодополнение вручную |
| `Tab` / `S-Tab` | выбрать вариант автодополнения / прыжок в сниппете |

## 6. Git

| Клавиши | Действие |
|---|---|
| `<leader>gs` | git-статус (fugitive): стейдж `-`, коммит `cc`, история `:Git log` |
| `<leader>gc` | коммит (fugitive) |
| `<leader>gp` | push |
| `<leader>gP` | pull |
| `<leader>gb` | git blame текущего файла |
| `<leader>gl` | граф истории (flog) |
| `[c` / `]c` | прыжок к предыдущей/следующей правке (gitsigns) |
| `<leader>hp` | превью диффа правки (gitsigns) |
| `<leader>hs` / `<leader>hr` | стейдж правки / откат правки (gitsigns) |

## 7. База данных (vim-dadbod)

| Клавиши | Действие |
|---|---|
| `<leader>db` | открыть обзорщик базы (DBUI) |
| `<CR>` | в DBUI: открыть таблицу |
| `S` | в DBUI: открыть таблицу в вертикальном сплите |
| `<Leader>S` | выполнить SQL-файл целиком (в visual-режиме — только выделенное) |
| `<Leader>W` | сохранить текущий SQL-запрос (dadbod-ui) |
| `:SshTunnel 3306` | открыть туннель к MySQL на сервере (нужно до DBUI) |

## 8. Локальная история версий (undo)

| Клавиши | Действие |
|---|---|
| `u` / `Ctrl+r` | undo / redo (обычные шаги) |
| `<leader>fu` | вся история файла: поиск и откат к любому состоянию (переживает перезагрузку) |
| `:undolist` | список веток undo |
| `g-` / `g+` | назад/вперёд по undo-веткам (time travel) |

## 10. Вид интерфейса (тумблеры `<leader>u`)

| Клавиши | Действие |
|---|---|
| `<leader>ud` | показать/скрыть ошибки и предупреждения LSP |
| `<leader>uw` | перенос длинных строк вкл/выкл |
| `<leader>uF` | авто-формат при сохранении вкл/выкл |
| `<leader>us` | проверка орфографии вкл/выкл (русский + английский) |

## 11. Справка

| Клавиши | Действие |
|---|---|
| `<leader>?` | все комбинации текущего буфера (which-key) |
| `<leader>fh` | поиск по документации (Telescope help_tags) |
| `:h {тема}` | встроенная справка по теме |
| `:checkhealth` | диагностика конфигурации |

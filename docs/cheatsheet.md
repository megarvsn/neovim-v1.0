# Шпаргалка: рабочий цикл

Тот же материал, что в [keymap.md](keymap.md) (клавиши по разделам) и
[commands.md](commands.md) (`:команды`), но в порядке работы: раздел = шаг
сеанса, в таблице «что хочу сделать → что нажать».

Один сеанс выглядит так:

```
открыть файл → править → искать/заменять → довести до ума → коммит → push
  (1)          (2–3)      (4–5)            (6)          (7)      (7)
```

## 1. Открыть, переключиться, сохранить

| Надо сделать | Клавиши |
|---|---|
| открыть файл по имени | `<leader>ff` |
| недавно открытые файлы | `<leader>fo` |
| дерево файлов проекта | `<leader>e` |
| переключиться между открытыми файлами | `<leader>fb`, или `<Tab>`/`<S-Tab>` |
| открыть ещё один файл рядом (сплит) | `\|` (вертикально) / `\` (горизонтально) |
| перейти в окно: влево/вниз/вверх/вправо | `<C-h>` / `<C-j>` / `<C-k>` / `<C-l>` (работает и для дерева, и для панелей) |
| размер окна: шире/ниже/выше/уже | `Alt+` `h` / `j` / `k` / `l` |
| сохранить | `<leader>w` |
| открыть файл в другой кодировке (Bitrix: windows-1251) | `:e ++enc=windows-1251` |
| поменять кодировку буфера перед сохранением | `:set fenc=utf-8`, затем `<leader>w` |
| закрыть буфер | `<leader>bd` |
| закрыть все вкладки, кроме текущей | `<C-x>` |
| выйти из Neovim | `:wa` затем `:qa` |

## 2. Переместиться к месту правки

| Надо сделать | Клавиши |
|---|---|
| двигаться по словам | `w` / `b` / `e` |
| начало / конец строки | `0` / `$` |
| к строке N / в конец файла | `12G` / `G` |
| к парной скобке / тегу | `%` |
| до символа x | `f{x}`, повтор `;`, назад `,` |
| прыжок к любому слову на экране | `s` (leap) |
| назад / вперёд по истории прыжков | `Ctrl+o` / `Ctrl+i` |
| вернуться, куда только что прыгнул | `''` |
| центр экрана на текущей строке | `zz` |

## 3. Внести правку

| Надо сделать | Клавиши |
|---|---|
| заменить слово / содержимое кавычек / внутри тега | `ciw` / `ci"` / `cit` |
| удалить тег целиком / строку | `dat` / `dd` |
| скопировать строку / блок в скобках | `yy` / `ya(` |
| вставить после / до курсора | `p` / `P` |
| новая строка после / перед | `o` / `O` |
| повторить последнее изменение | `.` |
| отменить / вернуть | `u` / `Ctrl+r` |
| вставить текст в начало колонки из N строк | `Ctrl+v` → вниз → `I` → текст → `<Esc>` |
| склеить две строки | `J` |
| поменять регистр/размер числа | `~` / `Ctrl+a` |

## 4. Найти

| Надо сделать | Клавиши |
|---|---|
| искать по файлу вперёд / назад | `/текст` / `?текст`, далее `n`/`N` |
| искать слово под курсором | `*` |
| снять подсветку поиска | `<Esc>` |
| нечёткий поиск по текущему файлу | `<leader>f/` |
| увидеть все совпадения проекта списком | `<leader>fw`, потом `<C-q>` в выдаче |
| следующий / предыдущий результат списка | `]q` / `[q` |
| история поисков списком (прыгнуть и повторить) | `q/` |

## 5. Заменить

| Надо сделать | Клавиши |
|---|---|
| заменить всё в файле сразу | `:%s/old/new/g` |
| заменить в файле с подтверждением каждого | `:%s/old/new/gc` (ответы: `y n a q l`) |
| заменить по проекту | `:vimgrep /old/ **` → `:cfdo %s/old/new/g` → `:cfdo update` |
| то же через поиск Telescope | `<leader>fw` → `<C-q>` → `:cfdo %s/…/…/g` |
| заменить по проекту выборочно, с превью | `<leader>fs` (Spectre): `<leader>R` — все, `<leader>rc` — строка, `dd` — исключить |
| заменить только слово целиком | `:%s/\<btn\>/button/g` |
| счётчик вхождений | `:%s/pattern//gn` |
| удаление строк по шаблону / пустых | `:g/pattern/d` / `:v/\S/d` |
| отредактировать/повторить прошлую Ex-команду | `q:` (окно истории) |
| синтаксис регулярных выражений | [regex.md](regex.md) |

## 6. Довести код до ума

| Надо сделать | Клавиши |
|---|---|
| увидеть ошибки файла / всего проекта | `<leader>qQ` / `<leader>qq` |
| прыжок к следующей ошибке | `]d` |
| к определению символа (html-класс → стили) | `gd`, список в css/scss — `<leader>lC` |
| все места класса/ID/функции по проекту (определения+ссылки) | `<leader>cl` |
| документация по символу | `K` |
| переименовать символ по проекту | `<Leader>lr` |
| быстрое действие | `<Leader>la` |
| отформатировать | `<Leader>lf` |
| символы файла по заголовкам | `<leader>cs` |

## 7. Провести через git

| Надо сделать | Клавиши |
|---|---|
| статус: смотреть и стейджить | `<leader>gs`, в панели `-` — стейдж/снять файл, `cc` — коммит |
| написать коммит | `<leader>gs` → `cc` (или `<leader>gc`) |
| отправить / получить | `<leader>gp` / `<leader>gP` |
| кто и когда менял строку | `<leader>gb` |
| граф всей истории | `<leader>gl` |
| у строки в коде: стейдж / откат правки | `<leader>hs` / `<leader>hr` |
| превью диффа правки строки | `<leader>hp` |
| прыжок к следующей правке | `]c` |

## 8. Сервер, база, терминал

| Надо сделать | Клавиши |
|---|---|
| смонтировать / отмонтировать проект с сервера | `:SshfsMount имя` / `:SshfsUnmount имя` |
| получить доступ к БД сервера | `:SshTunnel 3306` |
| открыть обзорщик базы | `<leader>db`; таблицу открывает `<CR>`, `S` — сплит |
| выполнить SQL-файл / выделенное | `<Leader>S` |
| терминал внутри редактора | `Ctrl+\`, выход в редактор — `jj` |
| открыть файл в браузере (вёрстка) | `<leader>o` |

## 9. Если что-то пошло не так

| Надо сделать | Клавиши |
|---|---|
| откатить файл к любой точке истории (после правок и перезагрузки) | `<leader>fu` |
| вернуться на 5 минут / 10 правок назад | `:earlier 5m` / `:earlier 10` |
| забыли клавишу | `<leader>` и подержать; все буфера — `<leader>?` |
| поиск по документации | `<leader>fh`, `:h {тема}` |
| диагностика конфигурации | `:checkhealth` |

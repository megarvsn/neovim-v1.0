## Режимы магии

В Vim-regex «специальность» символа зависит от режима (`:h magic`). Два рабочих режима:

- **magic** (по умолчанию): особые без бэкслеша — `.` `*` `[` `~`; остальное —
  после `\`: `\(`, `\+`, `\|`, `\<`, `\{n,m}`.
- **very magic** (`\v` в начале шаблона): всё спе́циальное — без бэкслеша,
  как в «обычных» регулярках. В сложных шаблонах рекомендуемый режим.

Обратная сторона `\v`: экранирование инвертируется — `\` перед специальным
символом делает его литеральным:

```vim
/\v(\d{2}):(\d{2})      " часы:минуты; ( ) и { } — спецсимволы
/\v\(                   " литеральная скобка '('
/\v\$5                  " литеральный '$'
/\vd{2}                 " литеральное 'dd': буква d — просто буква (цифра была бы \d)
```

Буквы, цифры и `_` в `\v` — литеральные символы; кавычки `'` и `"` — тоже
(экранировать не нужно). Полная таблица — ниже.

Сравнение одного шаблона (слова с дефисом):

```vim
/\w\+-\d\+              " magic
/\v\w+-\d+              " very magic — то же самое
```

Есть и «антирежимы»: `\V` (very nomagic) — всё буквально, спецсимволы только
после `\`; `\M` (nomagic) — промежуточный. Для повседневной работы не нужны,
знайте, что они есть (`:h /magic`).

## Метасимволы

| Смысл | magic (по умолчанию) | в `\v` |
|---|---|---|
| любой символ | `.` | `.` |
| «0 и более» предыдущего элемента | `*` | `*` |
| «1 и более» | `\+` | `+` |
| «0 или 1» | `\?` или `\=` | `?` или `=` |
| повтор от n до m раз | `atom\{n,m}` | `atom{n,m}` |
| лениво «0 и более» | `atom\{-}` | `atom{-}` |
| ИЛИ | `\|` | `|` |
| группа (с запоминанием) | `\(...\)` | `(…)` |
| группа без запоминания | `\%(...\)` | `%(…)` |
| начало / конец слова | `\<` / `\>` | `<` / `>` |
| начало / конец строки | `^` / `$` | `^` / `$` (литерал — `\^` / `\$`) |
| цифра | `\d` | `\d` |
| не цифра / не `\w` / не `\s` | `\D` / `\W` / `\S` | так же |
| пробельный символ (пробел, таб) | `\s` | `\s` |
| НЕ пробельный | `\S` | `\S` |
| буква | `\a` | `\a` |
| слово (буква/цифра/`_`) | `\w` | `\w` |
| игнорировать регистр / обязательно учитывать | `\c` / `\C` | так же |

Обратный слеш в `\v` делает специальный символ литеральным, а не наоборот —
это главное отличие от magic: `\(` — литерал, `(` — группа, `\<` — литерал.

## Классы символов

```vim
[abc]          " любой из: a, b, c
[a-z0-9]       " диапазон: строчные и цифры
[^abc]         " всё, кроме этих символов
[[:digit:]]    " POSIX-класс: цифры (внутри '[]', а не shorthand '\d')
```

- Внутри классов экранирование упрощается: `]` — как `\]`, `-` последним
  символом — буквально, `\` — `\\`.
- **Короткие классы `\d`/`\w`/`\s` внутри `[ ]` НЕ работают** (документировано
  в `:h /\[`): не сработает `\d`. POSIX-версия — `[[:digit:]]`, и она понимается
  vim-regex.
- Полезные POSIX-классы: `[[:digit:]]`, `[[:alpha:]]`, `[[:alnum:]]`,
  `[[:space:]]`, `[[:upper:]]`, `[[:lower:]]`, `[[:punct:]]`.

## Повторы

```vim
/colou\?r              " color и colour
/\vhttps?=             " http и https
/ba\{2,3}d             " 'baad' и 'baaad' — но не 'bad' и не 'baaaad'
```

**Жадность.** `*`, `\+`, `\{n,m}` жадные — берут как можно больше.
Ленивые версии — с `-` в фигурных скобках:

```vim
" было:  BEGINaEND BEGINbEND
:%s/BEGIN.\{-}END/OK/g      " лениво:  OK OK
:%s/BEGIN.*END/ONE/g        " жадно:   ONE (одно совпадение на всю строку)
```

- `\{-}` — «0 и более, как можно меньше»; `\{-1,}` — «1 и более, лениво»;
  `\{-n,m}` — от n до m, лениво.

## Слово, якоря, границы совпадения

- `\<` и `\>` — начало и конец слова (граница на стыке `\w`/не-`\w`):

```vim
" было:  mid=1        id=1 width=2
:%s/\<id\>/ident/g     " mid=1   ident=1 width=2  (внутри mid и width не тронет)
```

- `\zs` — «совпадение начинается здесь», `\ze` — «здесь заканчивается».
  Позволяет заменить только часть, не трогая якорные места:

```vim
" было:  href="old.png"
:%s/href="\zs[^"]*\ze"/NEW/      " → href="NEW"
```

- `^` и `$` — начало и конец строки. В magic они буквальны, если стоят
  не в начале/конце шаблона; в `\v` — напротив: всегда спецсимволы,
  литеральная версия — `\^` и `\$`.

## Группы и ссылки

- `\(...\)` (в `\v` — `(...)`) — запоминающая группа. В шаблоне на неё можно
  ссылаться `\1`…`\9`, в замене — тоже:

```vim
" поиск повтора слова подряд: 'abc abc'
/\v(<\w+>)\s+\1
:g/\v(<\w+>)\s+\1/d    " удалить строки с удвоившимся словом

" было:  one 'two' three
:%s/'\([^']*\)'/"\1"/g    " → one "two" three
```

- Не запоминающая группа `\%(...\)` (в `\v` — `%(…)`): группировка без сдвига
  нумерации `\1`…`\9`.

## Регистр

- По умолчанию поиск регистрозависимый (опция `ignorecase` в этом конфиге
  не включена).
- `\c` в любом месте шаблона — отключить учёт регистра; `\C` — включить
  принудительно (для шаблона в целом).
- В замене то же самое флагами: `:%s/old/new/gi` (`i` — без учёта), `:I` —
  с учётом.
- В Telescope/Spectre поиск идёт ripgrep'ом, регистр — по-разному:
  Telescope live_grep использует «умный» регистр (smart-case: шаблон из
  строчных букв ищет без учёта регистра, с заглавной — строго);
  Spectre по умолчанию регистрозависим — переключатель «без учёта»: `ti`.

## Многострочность

- `\n` — перенос строки в шаблоне (не «0 и более»).
- `\_s` — «пробельный символ ИЛИ перенос строки»:

```vim
" было (две строки):  div,
"                      img,
:%s/\v,\_s+/, /g     " → 'div, img,' — запятая+переносы схлопнулись в ', '
```

- Классы с переносом: `\_s`, `\_d` (цифра или перенос), `\_a`, `\_w` и т.д. —
  с подчёркиванием после `\`.

## Правая часть `:s` (чем заменяем)

| Синтаксис | Что вставит |
|---|---|
| `\1`…`\9` | группы из левой части (`\0` — всё совпадение) |
| `&` | всё совпадение (литеральный амперсанд — `\&`) |
| `\r` | **новая строка** |
| `\n` | **не перенос!** нулевой байт NUL (в тексте выглядит как `^@`) |
| `\t` | табуляция |
| `\u` / `\l` | следующий символ — верхний/нижний регистр |
| `\U…\E` / `\L…\E` | всё до `\E` — верхним/нижним регистром |
| `\=` | вместо текста — выражение (`submatch(0)`, `submatch(1)`, `line('.')`…) |

Примеры:

```vim
" поменять местами группы: было 27.10.2026
:%s/\v(\d{2})\.(\d{2})\.(\d{4})/\3-\2-\1/g     " → 2026-10-27

" телефон: было '999 123 45 67'
:%s/\v(\d{3}) (\d{3}) (\d{2}) (\d{2})/(\1) \2-\3-\4/

" пронумеровать строки файла:
:%s/^/\=line('.').'- '

" увеличить каждое число на 1: было v1 v2
:%s/\d\+/\=submatch(0)+1/g                    " → v2 v3
```

## Диапазоны и разделители

- Диапазоны `:s`: `%` (весь файл), `5,12`, `'a,'b` (метки), `'<,'>`
  (визуальное выделение), `.` (текущая), `.+3` (относительные).
- Пустая левая часть — последний поиск: `:%s//new/g`. В `:g/<паттерн>/s//…`
  пустой `:s` берёт паттерн самой `:g`.
- Разделитель не обязан быть `/`: годится любой, кроме `\` и `"` — удобно,
  когда в шаблоне пути: `:%s#site/old#site/new#g`.

## Команды :g и :v

`:g/шаблон/команда` — выполнить команду Ex в каждой строке с совпадением
(`:h :g`); `:v/шаблон/команда` — во всех строках БЕЗ совпадения.

```vim
:g/pattern/d          " удалить все строки с паттерном
:v/\S/d               " удалить пустые строки (строки без непробельного)
:g/console\.log/p     " показать все строки с console.log
:%s/pattern//gn       " ПОСЧИТАТЬ совпадения, ничего не меняя (n — no-replace)
:g/pattern/s//NEW/g   " заменить только в строках, где уже есть pattern
```

- Паттерн `:g` запоминается как «последний поиск» — поэтому работает идиома
  `:g/pat/s//NEW/` с пустым шаблоном замены.
- Вместо `d` можно любую Ex-команду: `>`, `normal …`, `sort`…

## Рецепты

Быстрая шпаргалка «задача → команда» (все проверены на живых примерах):

| Задача | Команда |
|---|---|
| Добавить класс всем `class="…"` | `:%s/class="\([^"]*\)"/class="wrap \1"/g` |
| Дата `27.10.2026` → `2026-10-27` | `:%s/\v(\d{2})\.(\d{2})\.(\d{4})/\3-\2-\1/g` |
| Телефон `999 123 45 67` → `(999) 123-45-67` | `:%s/\v(\d{3}) (\d{3}) (\d{2}) (\d{2})/(\1) \2-\3-\4/` |
| snake_case → camelCase | `:%s/_\(\w\)/\u\1/g` |
| camelCase → snake_case | `:%s/\v([a-z])([A-Z])/\1_\l\2/g` |
| Убрать все html-теги в файле | `:%s/<[^>]*>//g` |
| Одинарные кавычки → двойные | `:%s/'\([^']*\)'/"\1"/g` |
| Схлопнуть двойные пробелы | `:%s/ \{2,}/ /g` |
| Удалить пустые строки | `:v/\S/d` |
| Найти/удалить удвоенное слово | `:g/\v(<\w+>)\s+\1/d` |
| Пронумеровать строки | `:%s/^/\=line('.').'- '` |
| Все числа +1 | `:%s/\d\+/\=submatch(0)+1/g` |
| Значение href (не трогая кавычки-якоря) | `:%s/href="\zs[^"]*\ze"/NEW/` |
| Заменить только слово целиком | `:%s/\<btn\>/button/g` |
| Склеить «запятая + перенос» | `:%s/\v,\_s+/, /g` |

## Проект: синтаксис ripgrep (Telescope, Spectre)

`<leader>fw` (Telescope live_grep), `<leader>fs`/`<leader>fS` (Spectre) и поле
поиска Spectre — это ripgrep. Отличия от vim-regex:

| Vim-regex | ripgrep |
|---|---|
| `\d` `\w` `\s` | так же |
| `\<` / `\>` (граница слова) | `\b` |
| `\+`, `\?`, `\{n,m}` | `+`, `?`, `{n,m}` (без бэкслешей) |
| ленивый повтор `\{-}` | суффикс `?`: `*?`, `+?`, `{n,m}?` |
| `\(` группа | `(` |
| `\|` альтернатива | `|` |
| обратные ссылки `\1` в шаблоне | нет |
| `\zs` / `\ze` | нет |
| lookahead / lookbehind | нет в базовом синтаксисе (есть с `-P`, движок PCRE2) |

Примеры: `\bbtn\b` — слово целиком; `(id|class)="` — альтернатива; `\d{2}:\d{2}` — время.

Замена в Spectre — обычный текст; для замен с группами (`\1`) используйте
`:cfdo %s/…/…/g` поверх результатов Telescope-поиска (глава 4 туториала).

Официальная документация: `:h pattern`, `:h substitute`, `:h :g`, `:h /\v`.

## Файлы и сессии

| Команда | Действие |
|---|---|
| `:w` / `:w {файл}` | сохранить / сохранить как |
| `:q` / `:q!` / `:wq` | закрыть / закрыть без сохранения / сохранить и закрыть |
| `:qa` / `:qa!` | закрыть всё (с сохранением/без) |
| `:e {файл}` | открыть файл |
| `:e ++enc=windows-1251 {файл}` | открыть файл в заданной кодировке (старые Bitrix-файлы) |
| `:set fileencoding=utf-8` | сменить кодировку буфера (запись следующей `:w`) |
| `:Gedit {файл}` | fugitive: открыть файл через git-хранилище |
| `:saveas {файл}` | сохранить под новым именем |
| `:set number` / `:set nonumber` | показать/скрыть номера строк (уже включены) |
| `:set wrap` / `:set nowrap` | перенос длинных строк (по умолчанию nowrap) |
| `:noh` | сбросить подсветку последнего поиска |
| `:vsplit` / `:split` / `:only` | вертикальный/горизонтальный сплит / закрыть прочие окна |
| `:vertical resize ±N` / `:resize ±N` | изменить ширину/высоту окна |
| `:buffers` / `:bnext` / `:bprev` / `:bd` | список буферов / следующий / предыдущий / закрыть |
| `:Ex` | встроенный файловый менеджер (netrw) |
| `:reg` | просмотр регистров (буфер обмена = `+`) |
| `:marks` / `:jumps` | список меток / список прыжков |
| `:retab` | пересчитать табы под текущие настройки (4 пробела) |
| `:sort` / `:sort i` / `:sort u` | сортировка выделенных строк (`i` — без учёта регистра, `u` — уникальные) |
| `:vimgrep /паттерн/ **` | найти паттерн по файлам (результаты в quickfix) |
| `:copen` / `:cnext` / `:cprev` / `:cclose` | quickfix-список: открыть/следующее/предыдущее/закрыть |
| `:cdo {команда}` / `:cfdo {команда}` | команда для каждой строки / каждого файла из quickfix (например, `:cfdo %s/old/new/g`, затем `:cfdo update`) |
| `:g/паттерн/{команда}` / `:v/паттерн/{команда}` | команда для строк с паттерном / без него (`:g/pattern/d`, `:v/\S/d`) |
| `:mksession! ~/.sessions/имя` | сохранить сессию (открытые файлы и окна) |

## Плагины и навигация

| Команда | Действие |
|---|---|
| `:Lazy` | панель менеджера плагинов (sync/update/restore) |
| `:Lazy sync` | синхронизация плагинов с конфигом |
| `:Lazy update` | обновить все плагины до последних версий |
| `:Lazy restore` | откатить плагины к версиям из lazy-lock.json |
| `:Telescope find_files` | поиск файла (= `<leader>ff`) |
| `:Telescope live_grep` | поиск текста по проекту (= `<leader>fw`) |
| `:Telescope buffers` | переключение буферов (= `<leader>fb`) |
| `:Telescope oldfiles` | недавние файлы (= `<leader>fo`) |
| `:Telescope resume` | вернуть последний список Telescope (= `<leader>fr`) |
| `:Spectre` | массовая замена по проекту (= `<leader>fs`) |
| `:Telescope help_tags` | поиск по документации (= `<leader>fh`) |
| `:Neotree left toggle reveal` | дерево файлов (= `<leader>e`) |
| `:Trouble diagnostics toggle` | панель ошибок (= `<leader>qq`) |
| `:Trouble symbols toggle` | символы файла (= `<leader>cs`) |
| `:WhichKey` | панель which-key |
| `:Dashboard` | вернуться на стартовый экран |

## LSP, автодополнение и форматирование

| Команда | Действие |
|---|---|
| `:LspInfo` | статус LSP-серверов в буфере |
| `:LspStart` / `:LspStop` / `:LspRestart` | запустить / остановить / перезапустить LSP в буфере |
| `:Mason` | общий менеджер пакетов (LSP, форматтеры, линтеры) |
| `:MasonLog` | логи установки пакетов |
| `:ConformInfo` | какие форматтеры работают в текущем файле |
| `:TSUpdate` | обновить tree-sitter грамматики |
| `:TSInstall {язык}` | установить грамматику |
| `:TSUninstall {язык}` | удалить грамматику |
| `:InspectTree` | показать дерево разбора файла (tree-sitter) |
| `:Inspect` | показать подсветку/сущность под курсором |

## Git (fugitive/flog/gitsigns)

| Команда | Действие |
|---|---|
| `:Git` | статус/стейджинг/коммит (= `<leader>gs`) |
| `:Git commit` | открыть сообщение коммита (= `<leader>gc`) |
| `:Git push` / `:Git pull` | отправить/получить (= `<leader>gp`/`<leader>gP`) |
| `:Git blame` | кто менял эти строки (= `<leader>gb`) |
| `:Git log` / `:Git log %` | история репозитория / файла |
| `:Git diff` | изменения относительно HEAD |
| `:Git checkout {файл}` | откатить файл к последнему коммиту |
| `:Git branch` / `:Git switch {ветка}` | список веток / переключить ветку |
| `:Git stash` / `:Git stash pop` | отложить изменения / вернуть |
| `:Git merge {ветка}` | влить ветку |
| `:Gwrite` / `:Gread` | закоммитить файл целиком / вернуть файл из коммита |
| `:Flog` | граф истории (= `<leader>gl`) |
| `:Gitsigns toggle_current_line_blame` | показывать blame прямо в строках |

## База данных (MySQL через SSH-туннель)

| Команда | Действие |
|---|---|
| `:SshTunnel 3306` | открыть туннель к MySQL на сервере (первым делом) |
| `:DBUI` | обзорщик базы (= `<leader>db`) |
| `:DBUIAddConnection` | добавить подключение (мастер диалогов) |
| `:DBUIFindBuffer` | найти в дереве буфер, связанный с таблицей |
| `:DBUIRenameBuffer` | переименовать буфер таблицы |
| `:DBUILastQueryInfo` | показать выполненный запрос и его результат |
| `:DB {url}` | привязать текущий буфер SQL к подключению (например `:DB mysql://user@127.0.0.1:3306/base`) |
| `:DBUIToggle` / `:DBUIClose` | открыть/скрыть / закрыть панель БД |

## Проекты с сервера (sshfs)

| Команда | Действие |
|---|---|
| `:SshfsMount {имя}` | смонтировать проект в `~/Projects/{имя}` |
| `:SshfsUnmount {имя}` | отмонтировать проект |
| `:SshfsList` | статус всех описанных проектов |

## История версий (undo)

| Команда | Действие |
|---|---|
| `:Telescope undo` | откат к любому состоянию (= `<leader>fu`) |
| `:undolist` | список undo-веток файла |
| `:earlier 5m` / `:later 5m` | время-перемещение: на 5 минут назад/вперёд |
| `:earlier 10` / `:later 10` | на 10 изменений назад/вперёд |

## Терминал

| Команда | Действие |
|---|---|
| `:ToggleTerm` | открыть/закрыть терминал (= `Ctrl+\`) |
| `:ToggleTerm dir=~/Projects` | терминал в заданном каталоге |
| `:ToggleTermSendCurrentLine` | отправить текущую строку в терминал |

## Диагностика конфигурации

| Команда | Действие |
|---|---|
| `:checkhealth` | полная проверка health всей конфигурации |
| `:checkhealth vim.lsp` | только LSP |
| `:messages` | последние сообщения/ошибки |
| `:Lazy profile` | скорость загрузки плагинов |

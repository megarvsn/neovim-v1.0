# Туториал: практическая работа с конфигурацией

Пошаговый курс с реальными примерами — проходить по порядку, каждую главу
выполнять в открытом проекте (лучше с реальной вёрсткой/кодом). Все клавиши
совпадают с тем, что настроено в конфигурации; полные таблицы — в
[docs/keymap.md](../docs/keymap.md), `:команды` — в [docs/commands.md](../docs/commands.md).

Подсказка на ходу: нажали `<leader>` и замерли — which-key покажет все доступные
комбинации с русскими подписями. `<leader>?` — все клавиши текущего буфера.

## Оглавление

1. [Первые шаги](01-first-steps.md) — стартовый экран, открытие файла, hjkl, правки, `:w`, `:q`
2. [Навигация по проекту](02-navigation.md) — Telescope (`ff`/`fw`), дерево файлов, окна/вкладки, leap
3. [Редактирование](03-editing.md) — операторы + текстовые объекты, поиск/замена, визуальный режим
4. [Поиск и замена](04-search-replace.md) — буфер / файл / проект: всё сразу или с подтверждением; регулярные выражения
5. [Ежедневный фронтенд (HTML/SCSS)](05-html-scss.md) — авто-теги, `gd` → стили, `%`, форматирование
6. [Работа с кодом: LSP](06-lsp.md) — автодополнение, ошибки, K, переименование, code actions
7. [Git-цикл](07-git.md) — знаки правок, стейдж, коммит, push, blame, граф истории
8. [Проект с сервера (sshfs)](08-server.md) — монтаж, работа с Bitrix-проектом, `.ignore`
9. [База данных](09-database.md) — SSH-туннель, DBUI, выполнение запросов
10. [История версий](10-undo-history.md) — persistent undo, поиск по истории, откат
11. [Справка и настройка](11-help-tuning.md) — which-key, темы, тумблеры, терминал, свои проекты/плагины

Время на главу ≈ 5–15 минут. Если какая-то клавиша не работает —
найдите её в `<leader>?` и проверьте контекст (см. главу 11).

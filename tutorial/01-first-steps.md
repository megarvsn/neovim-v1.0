# Глава 1. Первые шаги

Цель: спокойно открыть файл, освоить перемещение, поправить строку, сохранить и выйти.
Время: ~10 минут.

## Стартовый экран

Запустите `nvim` без аргументов — открывается dashboard-nvim:

- `f` — открыть файл (поиск; то же, что `<leader>ff` внутри)
- `e` — открыть дерево файлов
- `u` — обновить плагины (обычно не нужно; `:Lazy update`)

Нажмите любой «пустой» Escape-символ — экран закроется, и вы в обычном редакторе.
Вернуться на стартовый экран: `:Dashboard`.

## Открытие файла

1. `<leader>ff` — нечёткий поиск по файлам проекта (Telescope). Наберите
   `main.scss` — список фильтруется на лету, `Ctrl+j`/`Ctrl+k` — перемещение по
   списку, `<CR>` (Enter) — открыть.
2. Точный путь тоже работает: `:e local/templates/main/header.php`.

> Сортировка нечёткая: достаточно частичного набора — `mains` найдёт `main.scss`.

## Перемещение (не трогая мышь)

| Клавиши | Что делает |
|---|---|
| `j` / `k` | строка вниз / вверх |
| `h` / `l` | символ влево / вправо |
| `w` / `b` | к следующему / предыдущему слову |
| `0` / `$` | начало / конец строки |
| `gg` / `G` | начало / конец файла |
| `12G` | перейти к строке 12 |
| `zz` | центрировать текущую строку на экране |

## Ввод и правка

- `i` — вставка перед курсором; `a` — после курсора; `o` — новая строка ниже.
- Выход из вставки: `<Esc>` или `jj`. Второе — настройка этого конфига:
  в русском тексте две буквы `jj` подряд почти не встречаются, поэтому
  вместо Escape можно просто дважды нажать `j`.
- Правим: `dd` — вырезать строку, `yy` — скопировать, `p` — вставить ниже.
- Ошиблись: `u` — undo, `Ctrl+r` — redo. Работает всегда, это главные клавиши.

## Практика (сделайте сейчас)

1. Откройте html-файл проекта (`<leader>ff`, Enter).
2. `G` — в конец файла; `gg` — в начало; `5j` — на 5 строк вниз.
3. Встаньте на любую строку, нажмите `yy`, затем `o` (новая строка) и `p`.
   Дубликат появился. Уберите его (`dd`) и отмените само удаление (`u`).
4. `<leader>w` — сохранить; `:q` — закрыть файл; `:qa` — закрыть Neovim.

## Что важно сразу понять

- Вкладки сверху (bufferline) — это **открытые файлы-буферы**, переключение
  `<Tab>` / `<S-Tab>`.
- Каждая правка записывается в **persistent undo** — история переживает
  перезагрузку (глава 9).
- Забыли клавишу? Нажмите `<leader>` и подержите — which-key подскажет все
  комбинации с русскими подписями.

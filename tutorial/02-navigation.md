# Глава 2. Навигация по проекту

Цель: за секундой находить нужный файл или место в большом проекте.
Время: ~15 минут.

## Поиск файла по имени: `<leader>ff`

Наберите часть имени: `header` — Telescope покажет `local/templates/.../header.php`
и всё похожее. `Ctrl+j/k` — список, `<CR>` — открыть, `<Esc>` — закрыть не выбрав.

Поиск идёт по всем файлам проекта (и по sshfs-монтированному).

## Поиск текста по проекту: `<leader>fw`

Это ripgrep «в прямом эфире»: набираете `nav-item` — видите все строки во всех
файлах, где есть эта строка. `<CR>` — открытие файла прямо на этой строке.

Практика: найдите `class="nav-`, выберите строку, нажмите `<CR>`. Открывшийся файл,
строка подсвечена курсором — можно сразу править.

## Дерево файлов: `<leader>e`

Открывает/закрывает боковую панель neo-tree. Полезные клавиши в панели:

- `<CR>` — открыть файл
- `a` — создать (имя с `/` в конце создаст папку)
- `d` — удалить, `r` — переименовать
- `c` / `x` / `p` — копировать / вырезать / вставить

## Открытые файлы: `<leader>fb`

Список открытых буферов — удобно, когда файлов много. Для пары файлов быстрее `<Tab>`/`<S-Tab>` по вкладкам сверху.

## Окна и вкладки

- `<C-h> <C-j> <C-k> <C-l>` — перейти в окно влево/вниз/вверх/вправо.
- Сплиты: `|` — вертикальный, `\\` — горизонтальный. Закрыть прочие окна: `:only`.
- `<Leader>x` — выбрать вкладку на закрытие; `<C-x>` — закрыть все, кроме текущей.

Практика: создайте сплит (`|`), откройте в нём scss-файл, переключайтесь
окнами `<C-l>` / `<C-h>`.

## Leap: прыжок в видимую точку — `s`

Прыгать колесом — долго. Вместо этого: `s` + 1–2 первые буквы целевого текста —
каждая точка экрана помечается буквой, нажимаете её — курсор там.
После прыжка работают обычные операции: `dtX` — удалить до символа, `c` — изменить.

- `S` — то же, но по всем открытым окнам (сравниваете два файла бок о бок)
- `gs` — прыжок к видимой точке в другом окне, файл открывается прямо там

Куда вы прыгнули — туда легко вернуться: `Ctrl+o` — назад, `Ctrl+i` — вперёд,
`''` — на место последнего прыжка.

Практика: вёрстка с двумя одинаковыми `<div>`: `s` + `na` — прыжок ко второму
(выбирайте букву-подпись у нужного вхождения).

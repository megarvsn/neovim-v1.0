# Глава 4. Ежедневный фронтенд: HTML + SCSS

Цель: освоить цикл вёрстки — ввод разметки, переход к стилям, форматирование.
Время: ~15 минут. Откройте html-файл из проекта.

## Авто-теги: пишете `<div>` — `</div>` приходит сам

Вставка режима: наберите `<div>` — закрывающий тег дописывается автоматически
(nvim-ts-autotag; курсор внутри пары). Работает на любом из двух тегов:

- переименование: встаньте на `div`, в обычном режиме `cwspan<Esc>` — оба тега
  станут `<span></span>` (и внутри php+html тоже)
- автозакрытие можно отключить в `lua/plugins/autotag.lua` (`enable_close = false`)

## Переход к стилям: `gd`

Курсор на имени класса в html → `gd` — открывается список определений этого
класса/ID во всех файлах стилей (.css/.scss/.sass/.less). `<CR>` — переход
к строке.

- Обычный CSS: находит `.имя` (и `#имя` для ID).
- SCSS-вложение: `.nav { &-item {} }` находится тоже — для `nav-item` в списке
  будет `&-item`. Для составных имён (`my-nav-item`) в списке могут быть и
  общие хвосты (`&-item`) — Telescope показывает файлы, выбор за вами.
- Из php-шаблона (или любого файла) та же функция глобально: `<leader>lC`.

Практика: найдите в вёрстке любой класс, `gd`, `<CR>` — вы в scss на правиле.
Вернитесь: `Ctrl+o`.

## Парные теги и скобки: `%`

- Курсор на имени тега: парный тег (открывающий ↔ закрывающий) подсвечивается.
- `%` — прыжок между парным тегом/скобкой. В длинном шаблоне — как кнопка «другой конец».
- `ds%` / `cs%` / `ys%` — операции по паре (удалить/изменить пару, окружить). Не
  пользуетесь — пропустите; `%` достаточно для навигации.

Вложенность тоже видна глазами: радужные цвета (`rainbow-delimiters`) красят
открывающий/закрывающий тег одного элемента одним цветом, уровни вложенности —
разными; вертикальные линии отступов показывают границы блоков.

## Форматирование и линтеры

- При `<leader>w` файл форматируется автоматически: prettier (html/css/scss/js/ts),
  sql-formatter (SQL), stylua (Lua).
- Ручной запуск: `<Leader>lf`. Какие форматтеры активны в файле: `:ConformInfo`.
- Авто-парные скобки и кавычки включены: `(` даст `()`, `'` даст `''`.
- Линтер (eslint) для js/ts: ошибки отображаются в тексте и в статусной строке
  при сохранении.

## Полный цикл (сделайте сейчас)

1. В html-файле добавьте новый блок: `<div class="new-block">Текст</div>`
   (закрывающий допишется сам).
2. `<leader>fw` — найдите `new-block`… ничего — стиля ещё нет.
3. Откройте главный scss (например через `<leader>ff`), добавьте:
   ```scss
   .new-block { padding: 12px; }
   ```
4. Вернитесь в html (`Ctrl+^` или `<leader>fb`), встаньте на `new-block`, `gd` —
   найдено, `<CR>` — прыжок к только что созданному правилу.
5. `<leader>w` в обоих файлах — всё отформатировано и сохранено.

# Глава 10. Справка и настройка под себя

Цель: уметь найти ответ о любой клавише, управлять внешним видом, терминалом
и добавлять свои проекты и плагины. Время: ~10 минут.

## Ключ-справочник: which-key

- Нажали `<leader>` и подержали секунду — все доступные комбинации с русскими
  подписями, сгруппированы (Поиск, Git, База данных, LSP…).
- `<leader>?` — все клавиши текущего буфера.
- Подсказка прерывается, как только вы нажали известную комбинацию полностью.

## Встроенная документация Neovim

- `<leader>fh` — поиск по справке (Telescope, help_tags).
- `:h {тема}` — конкретная тема (`:h :s`, `:h textobj`).
- Официальное руководство Neovim — лучший учебник по движению и правкам:
  `:Tutor` внутри редактора или [docs пользователя](https://neovim.io/doc/user/).

## Внешний вид

- Тема kanagawa, вариант задаётся в `lua/plugins/kanagawa.lua`; на лету:
  `:colorscheme kanagawa-dragon` (темнее) / `:colorscheme kanagawa-lotus` (светлая).
- Тумблеры: `<leader>ud` — показать/скрыть диагностические ошибки;
  `<leader>uw` — перенос длинных строк; `<leader>uF` — авто-формат при сохранении.

## Терминал внутри редактора

- `<C-\>` — открыть/закрыть терминал (в т.ч. здесь стартует SSH-туннель для БД).
- `jj` или `<Esc>` — фокус обратно в редактор; `<C-h/j/k/l>` — навигация по окнам.
- `:ToggleTerm dir=~/Projects` — терминал в нужном каталоге.

## Когда что-то не работает

1. `:messages` — последние сообщения/ошибки Neovim.
2. `:checkhealth` — общая диагностика (ищите ERROR/WARN).
3. `:LspInfo` — не подключился LSP-сервер в буфере?
4. `:Lazy` — панель плагинов: кто установлен, ошибки обновления.
5. `:Lazy profile` — скорость загрузки (что тормозит старт).

## Добавить свой проект (sshfs)

1. Откройте `lua/core/sshfs.lua` и скопируйте пример в таблицу `projects`.
2. `:source %` (или перезапуск Neovim), затем `:SshfsMount новое-имя`.

## Добавить плагин

1. Создайте файл `lua/plugins/<имя>.lua` (это импортируется автоматически):
   ```lua
   return {
       "автор/плагин",
       lazy = true, keys = { { "<leader>xx", "<cmd>Что-то<cr>", desc = "Описание" } },
   }
   ```
2. `:Lazy sync` — плагин поставится; версию зафиксирует `lazy-lock.json`.
3. Шапку файла оформляйте как у соседей: название + ссылка на GitHub + описание.

## Куда двигаться дальше

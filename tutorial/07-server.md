# Глава 7. Проект с сервера (sshfs)

Цель: открыть Bitrix-проект, который живёт на сервере, и спокойно править его в Neovim.
Время: ~10 минут + настройка. Полная справка: [docs/sshfs.md](../docs/sshfs.md).

## Настройка (один раз)

В `lua/core/sshfs.lua` опишите проекты:

```lua
local projects = {
    ["baza23"] = "baza23.ru:/home/bitrix/www",
}
```

Требование: ssh-ключ на сервере (`ssh baza23.ru` должен открываться без пароля),
macFUSE и sshfs установлены (см. [docs/install.md](../docs/install.md)).

## Работа

1. `:SshfsMount baza23` — серверный каталог смонтирован в `~/Projects/baza23`.
2. `<leader>ff` — ищите файлы как в обычной папке. При первом открытии файл
   скачивается сам (это делает sshfs); при `<leader>w` — сразу уходит на сервер.
3. `:SshfsList` — статус всех проектов; `:SshfsUnmount baza23` — отмонтировать.

Практика: смонтируйте свой проект, откройте вёрстку, измените строку,
сохраните — обновите страницу в браузере: правка уже на сервере.

## Исключаем серверный мусор (важно!)

sshfs ничего не фильтрует, а Telescope и LSP обходят дерево сами — иначе
в поиске всплывают кеш/upload/бэкапы. Поэтому в корне **монтированного проекта**
создайте файл `.ignore` (шаблон):

```gitignore
upload/
bitrix/cache/
bitrix/managed_cache/
bitrix/stack_cache/
bitrix/html_pages/
bitrix/backup/
bitrix/tmp/
```

- Для Telescope: файл `.ignore` (поймут и ripgrep, и fd).
- Дерево neo-tree и intelephense уже настроены на этот список отдельно
  (`lua/plugins/neo-tree.lua`, `lua/plugins/lsp.lua`) — скрывают `upload/` и
  битрикс-кеш, но показывают `.htaccess`.

## Хозяйство Bitrix-проекта

- Кеш (`bitrix/cache` и т.п.) и `upload/`: не трогаем, скрыты.
- Шаблоны в `local/templates/<имя>/` — основной рабочий путь вёрстки.
- Правки в БД (инфоблоки и т.п.) — отдельно от файлов: миграции через
  sprint.migration, см. [docs/sshfs.md](../docs/sshfs.md).
- Для серьёзной PHP-разработки есть и Способ 2: git + локальный web-стек — тоже
  в той же справке. Для вёрстки sshfs-способ основной.

## Терминал к серверу

`<C-\>` — терминал прямо в редакторе (в нем же открывается и SSH-туннель для
БД, см. главу 8). Из редакторского режима: `jj` — вернуть фокус в редактор.

# Глава 3. Редактирование: операторы, объекты, замены

Цель: править быстрее, чем мышью, используя текстовые объекты и глобальные замены.
Время: ~15 минут. Откройте html-файл с вёрсткой.

## Язык правок: оператор + текстовый объект

Формула всегда одна: «что сделать» + «с чем». Объекты: `i…` — «внутри», `a…` — «с границей».

- `iw` — слово, `i"` — содержимое кавычек, `iT`-аналог: `it` — содержимое HTML-тега,
  `it`/`at` — тег целиком, `i(` — в скобках.
- Операторы: `d` — вырезать, `c` — заменить (сразу входит в вставку), `y` — скопировать.

Примеры на реальной строке `<p class="lead">Текст</p>` (курсор в любом месте строки):

| Команда | Результат |
|---|---|
| `ci"` | заменить содержимое кавычек: класс становится пустым, напишите новый |
| `ciw` | заменить слово под курсором |
| `dit` | очистить содержимое тега `<p>` (текст внутри) |
| `dat` | удалить весь тег `<p>…</p>` целиком |
| `ya(` | скопировать функцию/блок в круглых скобках |

Главное правило: не нужно отсчитывать буквы и символы — говорите «внутри тега»,
и Neovim сам найдёт парную границу (по дереву Treesitter).

## Поиск и замена

- `/текст` — поиск вперёд, `n`/`N` — следующее/предыдущее, `<Esc>` — снять подсветку.
- `*` — поиск слова под курсором (без набора текста).
- `:%s/old/new/g` — заменить всё в файле; `gc` вместо `g` — подтверждение каждого вхождения (`y`/`n`/`a` — да/нет/всё).
- В визуальном выделении: выделили `V`, затем `:s/old/new/g` — заменить только в нём.
- `cgn` — заменить следующее совпадение и повторять остальное одной клавишей `.`:
  поиск `/class-item`, `cgnновое<Esc>`, далее просто `.` на каждом вхождении.
- Полезное: `:g/^$/d` — удалить пустые строки; `:sort` — сортировать выделенное.
- Массовая замена по всему проекту с превью каждой замены: `<leader>fs` (Spectre).
- Блоки кода сворачиваются по дереву Treesitter: `za` на теге/функции —
  свернуть/развернуть; `zR` — развернуть всё.

## Визуальный режим

- `v` — посимвольное, `V` — строки, `Ctrl+v` — колонка.
- В выделении работают операторы: `d`, `c`, `y`, `>` / `<` (сдвиг отступа), `J` (склеить строки).
- `vat` — выделить HTML-тег целиком; `vit` — только содержимое.
- Колонка (`Ctrl+v`): выделили колонку, `I` — вставить в начало каждой строки;
  `<Esc>` — и текст продублировался во все строки блока.

Практика (частая задача): к нескольким `<option>` добавить класс. Выделите
колонкой первые 3 строки, `I`, напишите ` class="sel"`, `<Esc>`.

## Повтор — `.`

`.` повторяет последнее изменение. Изменили класс правкой, прыгнули (`n`),
нажали `.` — тоже самое в новом месте. В связке с поиском (`*` + `n` + `.`) —
замена без всяких `:s`.
